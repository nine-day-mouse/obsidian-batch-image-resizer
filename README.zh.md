# Batch Image Resizer

[English](README.md) | 中文

把**当前笔记**里所有图片的显示尺寸批量改成同一个值，或者一键清除所有尺寸。支持中文 / English 界面。

改的是 Obsidian 的尺寸语法，不会动原图文件：

| 之前 | 之后 |
| --- | --- |
| `![[photo.png]]` | `![[photo.png\|500]]` |
| `![[photo.png\|300]]` | `![[photo.png\|500]]` |
| `![[photo.png\|300x200]]` | `![[photo.png\|500]]` |

## 三种用法

1. **点击左侧边栏的图片图标** —— 最快。点一下弹出尺寸输入框；弹窗左下角还有「清除尺寸」按钮，不用绕到命令面板。
2. **命令面板**（`Ctrl/Cmd + P`）
   - 设置当前笔记所有图片的尺寸
   - 清除当前笔记所有图片的尺寸
3. **编辑区右键菜单** —— 同样两项（仅编辑模式）。

在弹出的输入框里填 `500`（宽度）或 `500x300`（宽x高），回车即替换全文。弹窗里还有 `300 / 500 / 800 / 1000` 快捷按钮、一个「跳过手动调整过的图片」勾选框（见下文），以及左下角的「清除尺寸」按钮 —— 一键去掉本笔记所有图片的尺寸。

**阅读模式也能用**：命令不依赖编辑器。编辑模式下改的是编辑器缓冲区（可撤销），阅读模式下直接重写文件，视图会自动刷新。

## 语言

设置 → Batch Image Resizer → **界面语言**：

- **跟随 Obsidian**（默认）—— 与主程序语言保持一致
- **简体中文**
- **English**

切换后立即生效，包括左侧图标的提示文字和命令名称。

## 保护手动调整过的图片

批量改尺寸时，你可能不希望动那些**自己拖着边角调过**的图片。插件的判断依据是尺寸的**个位数**：

- 插件写入的尺寸都是 10 的整数倍（`300 / 500 / 800 / 1000`）
- 手动拖拽产生的尺寸通常不是（`437`、`512` …）

所以 **个位数不是 0 的尺寸，就视为手动调整过**。`500x37` 这种只要有一个数个位非 0，也算。

弹窗里的 **跳过手动调整过的图片** 勾选框控制本次是否执行这个跳过：

| 之前 | 之后 |
| --- | --- |
| `![[photo.png\|437]]` | 原样不动（视为手动） |
| `![[photo.png\|500]]` | `![[photo.png\|800]]` |
| `![[photo.png]]` | `![[photo.png\|800]]` |

需要注意：

- 约 **10% 的手动尺寸恰好是整十数**，这种情况保护不了，会被覆盖。反过来，插件写的值基本不会误判。
- **清除尺寸不受这个开关影响** —— 清除就是全清，这是刻意的。
- 别把「默认尺寸」设成非整十数（如 `456`），否则插件自己写的值也会被当成手动调整。

## 其它设置

- **默认尺寸**：对话框里预填的值，默认 `500`。
- **保护手动调整过的图片**：默认开启。关闭后，弹窗里不再显示勾选框，所有图片一律覆盖。
- **勾选框默认状态**：`固定打钩`（默认）/ `固定不打钩` / `记住上次的选择`。
- **同时处理 Markdown 图片**：默认关闭。打开后会额外处理 `![alt](image.png)` 形式，改成 `![alt|500](image.png)`。
- **跳过外部图片**：默认开启。`http(s)://` 和 `data:` 开头的图片不动。

## 行为说明

- 只处理当前打开的笔记，不扫描文件夹。
- 跳过围栏代码块（``` / ~~~）、`%%注释%%` 和行内代码 `` `…` `` 里的内容。
- 只认图片扩展名（png/jpg/jpeg/gif/bmp/svg/webp/avif/apng/ico/tif/tiff/jfif），所以 `![[某篇笔记]]` 这类嵌入不会被误改。
- 图片嵌入的 `|` 后面在 Obsidian 里就是尺寸，所以原来的 `|` 内容会被新尺寸覆盖。
- 编辑模式下走编辑器替换接口，可以 `Ctrl/Cmd + Z` 撤销。

## 安装到你的 Vault

1. 构建：

   ```bash
   npm install
   npm run build
   ```

2. 在你的 Vault 里建目录 `<Vault>/.obsidian/plugins/batch-image-resizer/`，把 `main.js`、`manifest.json`、`styles.css` 复制进去。
3. Obsidian 设置 → 第三方插件 → 关闭安全模式 → 找到 **Batch Image Resizer** 并启用。

## 开发

```bash
npm run dev     # esbuild watch
npm run build   # 类型检查 + 生产构建
```

文案都在 `i18n.ts`，新增一条只要在 `Messages` 接口和 `STRINGS.en` / `STRINGS.zh` 里各加一项即可。
